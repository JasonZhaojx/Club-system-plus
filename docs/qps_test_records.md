- 当前接口适合作为登录态查询的高并发基准接口。

结论：

`GET /api/users/me` 当前性能表现良好；在 80 线程、约 2360 QPS 下仍保持较低延迟。后续优化重点不是该接口本身，而是确认少量错误请求的具体状态码和原因。
